# WhisperTray 1.2.0 — проверка выпуска

Дата: 2026-09-07. Все размеры указаны в байтах.

## Изменения

Единый контроллер диктовки, файлов и подготовки модели; постоянный процесс распознавания с отменой и перезапуском; защита от устаревших событий и повторной вставки. Добавлены повтор неудачной диктовки в течение пяти минут, уровень сигнала, таймер, пробная запись, стадии обработки, действия с результатом и поиск истории. Исправлены конфигурация, очистка секретов, обработка ошибок и RU/EN-сообщения.

Один полный установщик сохраняет локальный движок и Groq. Модели загружаются отдельно. Стек приложения сохранён.

Для macOS 12 закреплены совместимые [ONNX Runtime 1.19.2](https://pypi.org/project/onnxruntime/1.19.2/) и [PyAV 14.2.0](https://pypi.org/project/av/14.2.0/), включая их транзитивные зависимости. Windows и Linux сохраняют ONNX Runtime 1.28.0 и PyAV 18.0.0. Все зависимости для сборок с Python 3.11/3.12 закреплены; новые прямые зависимости для функций приложения не добавлялись.

## Автоматические проверки

- Полный локальный pytest: 127 проверок успешно; Ruff и компиляция исходников также прошли.
- [CI на Windows, macOS и Linux](https://github.com/KROU4/Whisper-Tray/actions/runs/34098231107): по 127 успешных проверок на каждой ОС.
- Ruff, компиляция исходников, проверка версии, состава sources и закреплённых зависимостей.
- Briefcase packaged smoke проверяет Qt 6.8.1, версию 1.2.0, встроенный ONNX-детектор речи на синтетической тишине, реальный процесс распознавания, классифицированный ответ, принудительное завершение и новый процесс после перезапуска.
- Тесты проверяют отмену, сроки хранения WAV, ошибки сохранения, повреждение конфигурации, приватность, гонки событий, повторные записи, закрытие диалогов во время фоновой операции и интерфейс на малом экране.

## Распознавание

Шесть синтетических фраз: три русские и три английские. Пользовательские записи не использовались. [Машиночитаемые результаты](asr-verification-1.2.0.json).

Локальная модель tiny: итоговые тексты совпали с исходной версией во всех 6 случаях. В обеих версиях одно отличие от эталона связано с записью числа цифрами. Облегчённый вариант декодирования, ухудшивший одну русскую фразу, был исправлен и проверен повторно.

Groq: обработаны все 6 фраз; два отличия от эталона связаны с представлением чисел. Этот короткий набор подтверждает работоспособность, но не общую точность на произвольной речи. **Ускорение не заявляется**: измерения не показали основания для такого вывода.

## Ранее выполненная нативная проверка

Проверены первый запуск, оба профиля, захват горячей клавиши, пятисекундная пробная запись и прослушивание, начало и отмена записи, русский файл локально и английский файл через Groq, копирование, сохранение TXT и ограничение большого облачного файла. Вставка в Блокнот проверена с подготовленным аудио через замену источника записи; распознавание и ввод текста были реальными.

По результатам исправлены двойная реакция кнопки на сочетание с пробелом, обрезанное предупреждение о тишине, отсутствие отмены записи, открытие истории и поздние callback закрытых диалогов. Последующие изменения проверены автоматическими Qt-тестами.

По просьбе пользователя дальнейшие проверки через Computer Use прекращены. Финальная ручная проверка истории, браузерного поля, масштабирования и всех сценариев на macOS/Linux не заявляется.

## Установщик и выпуск

Первое обновление выявило пропуск двух DLL ONNX Runtime из-за правил версий MSI. Исправление задаёт замену библиотек приватного каталога приложения (`REINSTALLMODE=amus`), чтобы после удаления старой версии устанавливался именно закреплённый комплект. [Правила Windows Installer](https://learn.microsoft.com/en-us/windows/win32/msi/reinstallmode).

- Повторное обновление 1.1.4 → 1.2.0: MSI exit 0; все 3 122 файла совпали по SHA-256 с содержимым сборки; пользовательская конфигурация сохранила исходный SHA-256.
- Установленный Windows launcher распознал три синтетические фразы: процесс повторно использован для второй задачи и заново создан после принудительного завершения.
- Финальный CI-MSI проверен административным извлечением и запуском в отдельном каталоге. Пользовательская установка не заменялась; проверка обновления выше относится к локальной сборке.
- Итоговый CI-MSI: версия и `REINSTALLMODE=amus` подтверждены, все 30 исходных файлов совпали с репозиторием с учётом различий LF/CRLF; сохранён программный рендеринг Qt, QML исключён, тестовые исходники отсутствуют. Реальное распознавание трёх синтетических фраз, повторное использование процесса и перезапуск после завершения прошли.
- DEB установлен в чистый контейнер Ubuntu 24.04 через apt. Проверены объявленные зависимости, Qt Widgets, загрузка X11-плагина, PortAudio и процесс распознавания. Системный микрофон и дисплей не используются.
- macOS: нативный launcher завершил проверку Qt, ONNX/VAD и остановки/перезапуска рабочего процесса. Результат передаётся через свежий файл в изолированном временном каталоге: macOS 26 скрывает строки NSLog, включая прежний тестовый маркер Briefcase 0.3.25. Production DMG/PKG создаются до добавления тестовых исходников. Запуск проверен на ARM64-раннере; отдельная проверка Intel и реальной macOS 12 не выполнялась.
- DMG/PKG, MSI и DEB скачаны из [успешного релизного CI](https://github.com/KROU4/Whisper-Tray/actions/runs/34098231131) для коммита `2baca681a307ecc4899656efec7038775a98eb3e`. Размеры и SHA-256 всех четырёх файлов совпали с манифестами и серверными digest GitHub. [Машиночитаемый отчёт](package-verification-1.2.0.json).
- В извлечённом PKG подтверждены версия 1.2.0, минимальная macOS 12.0 и отсутствие тестовых исходников и временного адаптера логов. Архитектуры установщика: x86_64 и arm64; запуск проверен на arm64.
- GitHub заменяет `~` в имени DEB на точку. Манифест приведён к фактическому имени опубликованного файла; генератор манифестов теперь выполняет это преобразование перед загрузкой. Контрольная сумма установщика не меняется, проверка имени и SHA-256 прошла.
- [Релиз v1.2.0](https://github.com/KROU4/Whisper-Tray/releases/tag/v1.2.0) подготовлен через черновик после завершения сборок и проверки скачанных артефактов.

Предыдущий опубликованный релиз 1.1.4 сохраняется для отката. Установщики публикуются в GitHub Releases и не добавляются в историю исходников.
