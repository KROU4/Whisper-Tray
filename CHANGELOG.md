# История изменений

## 1.3.0 — 2026-10-07

- ИИ-оформление текста в режиме «Скорость»: после Whisper распознанный текст
  (не аудио) проходит через языковую модель Groq с тем же ключом — знаки
  препинания, удаление «э-э» и слов-паразитов, исправление ошибок
  распознавания. При любой ошибке вставляется исходная расшифровка. В режиме
  «Приватность» функция не работает. Включена по умолчанию, в том числе после
  обновления; отключается в «Настройки» → «Основное».
- Новый индикатор состояния: скруглённая капсула с иконкой, таймером и уровнем
  микрофона во время записи, спиннером при распознавании, зелёной галочкой
  после вставки и короткой янтарной подсказкой при ошибке. Индикатор не
  забирает фокус и скрывается сам.
- Системные уведомления трея больше не показываются для ошибок и служебных
  сообщений; подробности остаются в главном окне.
- Обновлены главное окно, настройки (редкие параметры собраны в
  «Дополнительно») и мастер первого запуска; новая палитра с проверенным
  контрастом.
- Режим удержания клавиши останавливает запись при отпускании любой клавиши
  сочетания и больше не запускает запись при отпускании.
- Записи без речи и случайные нажатия не отправляются на распознавание;
  фразы, которые Whisper «придумывает» на тишине, отбрасываются.
- Диктовка вставляется одной строкой, чтобы перенос не срабатывал как Enter и
  не отправлял сообщение в мессенджере раньше времени.
- Модель распознавания больше не перезагружается после изменения настроек,
  не связанных с ней.
- Установщик Windows: стандартный порядок шагов, ярлык на рабочем столе на
  экране выбора папки, обновлённые тексты и оформление.

## 1.2.0 — 2026-09-07

- Диктовка, файлы и подготовка модели используют единый контроллер задач и
  отдельный процесс распознавания. Добавлены отмена, повтор после ошибки и
  защита от запоздалой вставки текста.
- Исправлены повторный захват прежнего сочетания клавиш и автоостановка
  последующих десятиминутных записей.
- Добавлены уровень микрофона, таймер, предупреждение о тишине, пробная запись
  с прослушиванием и отображение стадий обработки.
- Результаты файлов видны в окне; доступны копирование, сохранение, открытие
  папки и поиск по необязательной локальной истории.
- Исправлены приоритет профиля приватности, восстановление повреждённой
  конфигурации и очистка секретов из traceback; диагностика ограничена
  разрешёнными полями.
- Повторы Groq ограничены одним механизмом, размер и формат файла проверяются
  до загрузки. Режимы обработки диктовки и файлов разделены.
- Windows MSI использует высокое сжатие и исключает ненужные компоненты Qt,
  сохраняя локальный движок. Зависимости нативной сборки закреплены.
- Исправлена замена библиотек локального движка при обновлении MSI с 1.1.4.
- Релиз создаётся черновиком и публикуется после проверки собранных пакетов.

## 1.1.4 — 2026-08-30

- Поле горячей клавиши в настройках стало доступно только для чтения: новое
  сочетание задаётся кнопкой «Изменить» и обычным нажатием нужных клавиш.
- Добавлены автоматические проверки кнопки захвата и сохранения `Ctrl+Space` в
  машинном формате `ctrl+space`.
- README дополнен инструкцией по получению Groq API-ключа и актуальными
  лимитами бесплатного плана.
- Добавлен двуязычный лендинг WhisperTray и автоматическая сборка для GitHub
  Pages.

## 1.1.3 — 2026-08-30

- Улучшены отступы и визуальная иерархия главного окна.
- Windows-установщик получил выбор каталога, лицензионное соглашение, создание
  ярлыка и исправленный запуск WhisperTray после установки.

## 1.1.2 — 2026-08-30

- Онбординг стал короче и яснее объясняет разницу между локальным режимом и Groq.
- Для каждого профиля показываются только относящиеся к нему действия и требования.
- Добавлена отдельная настройка запуска сразу в системном трее.
- Настройки запуска, истории и диагностики разделены на самостоятельные блоки.
- Техническая диагностика свёрнута по умолчанию, а сообщения первого запуска полностью локализованы.

## 1.1.1 — 2026-08-08

- Первый запуск теперь завершается переходом из онбординга в основное окно.
- Настройки разделены на понятные вкладки; диагностика перенесена внутрь настроек.
- Добавлено управление запуском WhisperTray вместе с системой.
- Windows MSI предлагает запустить приложение сразу после успешной установки.

## 1.1.0 — 2026-08-08

- Новый трёхэтапный онбординг с отдельными сценариями «Приватность» и «Скорость».
- Исправлена глобальная горячая клавиша `Ctrl+Space`, включая левый и правый Ctrl.
- Добавлена плавная анимация записи с поддержкой уменьшения движения.
- Настроены нативные сборки Windows, macOS и Linux через Briefcase.
- Добавлены русская и английская версии README.
- Усилены проверки конфиденциальности, диагностика и автоматические тесты.
